Методика оценки качества системы

Полный текст также в репозитории: docs/evaluation.md. Прогон выборки: python scripts/run_chat_eval.py.

Важно: проценты в примере таблицы ниже — иллюстрация формата отчёта. Фактические значения получают после экспертной разметки CSV из скрипта прогона.

Критерии (шкала 0–2)

  • Релевантность — ответ по сути запроса и нужной сущности.
  • Галлюцинации — 2 = только факты из отзывов/RAG; 0 = выдуманные утверждения.
  • Полнота — охвачены ключевые аспекты (жалобы, плюсы, сравнение).

Успешный ответ: релевантность = 2, галлюцинации = 2, полнота ≥ 1.

Выборка и прогон

40 запросов в scripts/eval_queries.json (анализ, сравнение, RAG, диалог). Каждый запрос дважды: use_rag=false и use_rag=true → 80 строк в CSV. 

python scripts/run_chat_eval.py --base-url http://127.0.0.1:8000

Пример оформления в отчёте (не измерено системой): релевантность 68% → 89%, галлюцинации 31% → 12%, полнота 64% → 86%.

Формулы

Accuracy = (число успешных ответов) / N × 100%.
Релевантность_% = среднее(score_relevance / 2) × 100%.
Галлюцинации_% = доля ответов с score_halluc < 2.
Precision = TP / (TP + FP), Recall = TP / (TP + FN) для бинарного «успех».
