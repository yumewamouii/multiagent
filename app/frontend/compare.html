Сравнение бок о бок

Сравните 2–6 клиник, услуг, направлений или врачей одним LLM-вызовом. На выходе — таблица метрик, победители, сильные/слабые стороны и USP по каждой (готовый материал для лендинга и рекламы).

Как пользоваться: выберите тип, начните вводить имена в поля «Сущность» — работает автодополнение из ваших данных. Для каждой строки можно нажать на одну из карточек ниже. Scope (опционально) сужает выборку отзывов: например, при сравнении клиник укажите service: Тонзиллор — и система оставит у каждой только отзывы по этой услуге.

Параметры

Сущности (от 2 до 6)

Подсказки

Клик добавит сущность в первое пустое поле выше.

Scope: сравнить в контексте

Заполните одно поле — отзывы по каждой сущности будут отфильтрованы. Полезно для USP: «сравни клиники по конкретной услуге».

Тонкая настройка

Тянем данные по каждой сущности и зовём LLM. Обычно 15–60 секунд.
