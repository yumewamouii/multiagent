Репутационный чат

«Проанализируй отзывы по услуге …», «Сравни клиники по этой услуге», «Что говорят про врача …». Контекст разговора сохраняется на этом устройстве — следующая реплика «а теперь по другой клинике» работает.

Что можно спросить:
  • «Проанализируй клинику Союз» — отчёт по одной сущности.
  • «Сравни Авиценна и Союз по услуге Тонзиллор» — сравнение со scope.
  • «Что говорят про длинные очереди?» — RAG-поиск по теме.
  • «А теперь по другой клинике» — наследует тип и интент предыдущей реплики.
Новая сессия
Спросите что-нибудь, чтобы начать. Например, «Проанализируй клинику Союз».
